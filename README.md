# Odd or Even Calculator

## This program checks if a number input by the user (num) is odd or even

## How to run
1. Open the program file using any IDE (e.g. VS Code, Google Colab)
2. Run the program
3. Enter a whole number
4. Check the output given by the program

## Sample Output
Enter num: 2
The number is even

Enter num: 3
The number is odd
